# 한글 조합 테스트 목록. 안드로이드 테스트와 나중의 iOS 테스트가 같은 파일을 읽는다.
# 형식: 기대 결과 | 입력 | 출처
# 입력: 자모를 공백으로 구분한다. 앞에 ~가 붙은 키는 바로 전 키와 간격 < T, 없으면 간격 ≥ T다. ⌫는 DEL.
# 출처: 실측(기존 키보드에서 사용자가 확인), 규칙(조합 규칙에서 끌어낸 값, 기존 키보드에서 확인되면 실측으로 바꿈), 임시(확인 전 임시 규칙 기준).
# '빠르게 치면 붙는 단어' 묶음은 결과가 이상해 보여도 기대 결과가 맞다.
